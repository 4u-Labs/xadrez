## ⚡ Recursos e Arquitetura

O **Xadrez Clássico 4U.IA.BR** é um jogo de xadrez completo desenvolvido em **JavaScript Puro (Vanilla JS)** com inteligência artificial baseada no algoritmo **Minimax com Poda Alpha-Beta** e tabelas posicionais de peças.

### 🌟 Destaques:
* 🔊 **Sintetizador Web Audio API Puro:** Efeitos sonoros realistas gerados matematicamente no navegador (som de peça de madeira, captura pesada, alerta de xeque, roque, promoção e fanfarra de vitória/derrota).
* 📋 **Notação Algébrica Real (SAN):** Registro fiel de lances no padrão internacional dos torneios.
* 📋 **Exportação PGN & FEN:** Copie o PGN completo ou o FEN da posição em 1 clique para análise externa no Lichess/Chess.com.
* 🤖 **Níveis de Dificuldade:** Fácil (Profundidade 2), Médio (Profundidade 3) e Mestre (Profundidade 4).
* 📱 **PWA Offline:** Totalmente instalável e funciona sem internet.
